# 知识库2 · Seedance 2.0 提示词编写经验库

> 用途：供「爆款视频分析改写官」调用，把拆解出的爆款骨架，写成**专业、画面感极强、可直接粘贴**的 Seedance 2.0 提示词。
>
> ⚠️ **本文件只教写法，不定义产品。** 文中出现的"白云山二硫化硒洗发水 / 去屑 / 头屑 / 马拉色菌"等一律是**写法示范用的示例产品**，用来演示"这种质感的中文该怎么写"。
> **实际脚本里的产品名、卖点、成分、数据、场景，一律以本 GPT 挂载的【知识库3·产品卖点库】为准。** 换产品时本文件无需改动，只需在阅读范例时把示例产品替换成当前挂载产品。
>
> 一句话内核：**把提示词当成一份"用文字拍出来的画面"，像写小说一样具体地描述，让任何人读完文字，脑海里就能浮现对应的画面和运动。**

---

## 0. 六条核心信念（贯穿全程）

0. **先识别、再改写；风格照搬、只换产品。** 动笔前先识别原片的**画风/风格 + 内容类型/表现形式**（§13）。改写时**原样保留原片的：①主题风格与画风 ②叙事逻辑 ③画面表现形式**；**只把"产品本体及相关内容"换成本产品**（本产品 = 知识库3 挂载的产品；例：自行车→本产品、骑行比赛→本产品主功效比拼）。**绝不把动画改成真人实拍，没有"默认风格"这回事——参考片是什么风格，就写什么风格。**
1. **全程中文、像写小说一样写画面。** Seedance 2.0 更吃中文描述。用具体、连贯、有画面感的中文，把"谁、在哪、什么样子、做什么、镜头怎么动、什么情绪"揉进流畅的叙述里——读者看文字就能在脑海里放出这段视频。**这是第一原则**（写法见 §12）。
2. **提示词 = 拍摄剧本。** 交代清楚每个角色、每个元素的细节，再说清画面如何运动。
3. **静态定义 与 动态发生 分开建。** 先把"世界"交代清（角色/场景/画质质感），再在世界里写"动作"——但最终可以融成连贯叙述，不必生硬分段。
4. **只用正向描写，不写负向指令。** **不要写"禁止/杜绝/不要 XX"这类负向清单。** 想要真实感，就正面把它描述出来（如"皮肤有真实毛孔与纹理、自然日光、轻微胶片颗粒、生活化的随意感"），而不是写"禁止过度磨皮/杜绝 CG 感"。要什么画面就描述什么画面。
5. **抽卡心态。** AI 不一定完全跟提示词走，崩坏是通病；提示词是提高命中率，不是保证。多生成几次。

## 1. 撰写结构：分区块的拍摄剧本

前几块是"不变的设定"，最后一块是"随时间发生的事件"。骨架固定：

| 区块 | 作用 | 包含 |
|---|---|---|
| **【基础设定】** | 选角 + 置景 | 角色、道具、场景、声音规则 |
| **【氛围与画质】** | 定调 | 风格核心、摄影机/镜头、色彩影调、质感（全用正向描写） |
| **【画面内容】** | 定机位 + 表演调度 | 分镜、景别、构图、运镜、动作流 |

**最关键洞察：静态定义 与 动态发生 必须彻底分开。先建稳世界，再放动作。**

---

## 2. 动作流的两种模式

| 模式 | 适用 | 写法 |
|---|---|---|
| **A. 单镜头一镜到底** | 单一连续动作、追逐、长镜头、变身 | 一段连续文字，靠时序词串因果链 |
| **B. 多分镜** | 战斗、多动作、节奏切换（**多数带货/爆款短视频属此类**） | 拆成分镜，每个独立成行 |

**两种模式都用「时间码 + 功能命名」切段：**
- 功能命名 = 用戏剧/内容功能起名（如：痛点开场 / 产品亮相 / 起泡按摩 / 成分溯源 / 数据展示 / 美好收尾），**不要叫"镜头1、镜头2"**。
- 格式示例：`镜2 · 起泡按摩（3-5s） 运镜：[运镜] —— [动作内容]`

---

## 3. 时长 ↔ 动作密度 换算（控制节奏）

| 节拍 | 时长 |
|---|---|
| 一次完整动作（如：起泡→揉搓→冲净一气呵成） | ≈ 1.5s |
| 一个分镜塞两个动作 | ≈ 2s |
| 慢节奏收尾/转场（动作少、留呼吸） | ≈ 3–4s |
| 单一阶段动作（如一个产品特写） | ≈ 3s |
| 开场单一入画动作 | ≈ 1.5s |

**法则：15s ≈ 8 分镜 / 约 10–12 拍。动作越密单拍越短；要让动作看得清，1.5s 内别塞超过 1 个连贯动作，塞太多 = 糊成一团。**

## 4. 图片引用规则（务必遵守的反直觉主张）

- **引用图片 = 跨镜头/跨系列必须保持一致的"视觉身份"，且参考图本身必须高画质时才用。** 图管"是什么样"，文字管"做什么"。
- **能不用参考图就不用。** 造型/场景靠文字描述让 AI 自由发挥，更独特也更出片。
- **低画质 / 过度美颜的参考图会把画面拖成"五毛特效 / 国产 CG"。** 只有 ①画质极高贴近真实 或 ②3D 渲染图 才值得喂。
- **不要用 AI"洗一遍"或做"创作分身"**，会失真、不像本人。
- **人脸特例**：要像本人就喂脸图，且必须清晰、不过度美颜、甚至素颜（"过于完美就假，保留缺陷才真"）。人脸审核不过：换图 / 忽略提示继续生成 / 先用其他工具生成超写实人像再用。
- **应用**：产品包装（如有官方高清图）可引用以保持一致；真人形象优先用清晰素颜级脸图或干脆文字描述；成分、质地、功效示意画面等靠文字描述即可。

**@素材码内联引用写法（重要）：** 在视频生成任务里，引用的图片素材用 `@` + 一串字母数字（如 `@e9e1e830-212a-476f-b95a-01e49c5f1eb8`）表示，看起来像乱码，但它就是"这张图"。**写法是把 @素材码直接内联写进描述里、紧挨着它指代的对象**，例如"孩子穿着这双 @素材码 正心 AI 宽宽鞋"。同一素材在多个分镜出现就重复引用同一个码，以锁定跨镜头一致。
- 智能体自己**不知道用户的真实素材码**，输出时用占位写法提示用户替换，例如：`@产品瓶图` / `@真人脸图` / `@场景图`，并在交付时说明"把 @占位 替换成你上传素材对应的码"。

## 5. 真人实拍风格的默认值（仅当参考片是真人实拍时套用）

> ⚠ 这一节只在**参考视频本身是真人实拍**时才用。参考片是动画/拟人化/其他风格时，**不要套这套电影实拍参数**，改按 §11 对应风格写、忠实贴合原片画风。

- **视觉基调**：模拟 IMAX 胶片摄影机，搭配 Panavision C 系列镜头（约 35mm，f4），添加动态模糊。
- **拍摄方式服务情绪**：稳定/展示 → 固定机位跟随；紧张/痛点 → 手持 + 轻微抖动；仪式/凝重 → 手持呼吸般浮动。
- **色彩与影调**：低饱和高对比，胶片颗粒感，自然日光，高光不过曝、暗部保留细节，轻微柔焦。
- **品类调性补充（按知识库3 的品牌调性自定，不要写死）**：如洗护/科技类可叠加"干净通透、蓝白色科研科技感"；中药老字号/草本类可叠加"温润质朴、药堂木色暖调"。**以知识库3 §1 与差异化记忆点为准。**
- **真实感全用正向描写**（替代过去的负向清单）：要真实，就正面写"皮肤有真实毛孔与细纹、发丝有自然光泽与碎发、自然日光、轻微胶片颗粒、生活化的随意构图、动作连贯自然有重量感"。**不要写"禁止/杜绝 XX"。** 想让画面更干净就写"画面整洁、光线柔和均匀"；想要动作流畅就写"动作连贯顺滑、过渡自然"。

## 6. 必做的细节强化（让画面"活"起来）

写动作和特效时主动加，新手往往想不到：

1. **因果链 + 时序词**：随即、片刻后、0.3 秒后、间隔不足 0.3 秒……
2. **把抽象动作拆成可见身体细节**：不写"洗头"，写"指腹揉搓起泡、泡沫从发根铺开、手指按压头皮"。
3. **镜头对世界的物理反馈**：水流冲击 → 画面微抖；蒸汽 → 镜头轻微起雾，让镜头"在场"。
4. **打击/特效/卖点点名精确部位与尺寸**（举例，实际部位按知识库3 的功效部位来）：洗护类如"头顶发缝、发根 0.5cm、肩头白屑"；口腔类如"门齿唇面、近齿龈处 2mm 的黄渍带"；护肤类如"鼻翼两侧毛孔、颧骨斑点区"。
5. **亚秒级量化时序**：每秒泡沫递增、3 秒后头皮可见清爽——精确＝真实。
6. **量化空间定位**：画面中心线右侧、占二分之一、动态对角、距离不足 5 米。
7. **同期声控制**：把声音当成被导演的维度（水声、揉搓声 vs 旁白 vs 配乐，明确指令）。
8. **结尾可留白**：克制（没有夸张台词/特效）往往比炫技更高级。

---

## 7. 隐性技巧清单

- **7.1 正向描写代替负向**：要什么写什么，不写"禁止/杜绝"。要真实写"真实毛孔/自然光/胶片颗粒/动作有重量"；要纯净同期声就写"只有水声与揉搓声，安静无配乐"。
- **7.2 量化空间定位**：中心线右侧、占二分之一、动态对角。
- **7.3 同期声控制**：声音是一个被导演的维度。
- **7.4 专业摄影语汇**：用真实拍摄术语（机型/镜头/焦段/运镜），而非"很高级"。
- **7.5 多主体一致性 = 编号法**：多个对象逐个编号处理，防串戏。
- **7.6 镜头连续性 = 衔接词工程**：无缝衔接 / 无缝切 / 无跳切 / 全程贴脸。
- **7.7 拍摄方式服务情绪**：稳定展示→固定跟随；痛点紧张→手持抖动；仪式→手持呼吸感。
- **7.8 动作模板复用**：同类动作用同一句法，保一致出节奏。
- **7.9 表情/光效 = 颜色编码情绪节拍**（适用于机器人/LED 等，功效类产品可用于成分高光）。
- **7.10 钩子衔接**：开场钩子抓人；"画风转变"显式提示转折。
- **7.11 结尾留白哲学**：克制比炫技更高级。

## 8. 失败与避坑（最值钱部分）

**对随机性的认知（先建立心态）：**
- 同一提示词每次生成差别都很大；偶发的惊喜运镜无法复刻。
- → **抽卡式多生成几次**，别指望一次到位。

**防"五毛特效/CG 感"（真实感第一命题）：**
- 用清晰、不过度美颜、甚至素颜的真人图；"过于完美就假，保留缺陷才真"。
- 少喂参考图；差图不如不喂（见 §4）。

**模型与设置：**
- 用 **Seedance 2.0**，不要用 **2.0 fast**（fast 快但细节差）。
- **字数超限**：删减文案，或改用电脑网页版。
- 生成失败：直接重新生成。
- 长视频：用网页端「生成视频后续」功能续接。

**合规：**
- 涉版权（影视 IP / 名人 / 品牌字眼）：替换相关词语。
- 提示违规：随便删改个别字眼/标点，不改大意即可。

**主题一致性：**
- 基础服装/置景要贴合主题（"哪有人穿高跟鞋打架"），否则破坏沉浸感。

**自查：**
- 提示词易有错别字，用前自己检查一遍。

## 9. 提示词输出格式（最终交付）· 专业分镜脚本

> 核心要求：**全程中文、像写小说一样具体、只用正向描写、不写负向指令**。
> 框架参考好莱坞分镜表（shot list）的标准维度——镜号、场景、景别、机位角度、运镜、镜头/焦段、主体动作、音频、地点、时长、转场——并融入两条本项目特有要求：**画面"看图写话"** 和 **台词内联**。

### 9.1 整体结构

```
【脚本定位】画风：__ ｜ 内容类型：__ ｜ 主打卖点：__ ｜ 副卖点：__ ｜ 时长：__ ｜ 参考爆款骨架：一句话 ｜ 把原片的「X」换成本产品的「Y」

【基础设定】（不变的世界，先交代清，可用 @素材码 内联引用）
角色：@真人脸图 谁、长什么样、发丝/头皮状态、穿着、神情（多个同类对象编号 1号/2号…）
产品：@产品图 〔知识库3 里的产品全称〕，〔质地/颜色/包装样子，取自知识库3 §1〕
场景：地点、时间、天气、光线、背景元素
整体质感：风格关键词 + 情绪关键词 + 正向质感（真实毛孔/自然日光/胶片颗粒等）+ 与原片风格及知识库3 品牌调性相符的色调 + 默认镜头（电影实拍见 §5）
同期声：明确写（如"只有水声与揉搓声，安静"）；旁白/配乐/字幕属后期

【分镜脚本】（逐镜，每镜包含下列维度）
镜1 · [功能名]（0–Xs）
  景别/机位/运镜：[景别] + [角度] + [运镜方式]
  画面：看图写话式描述——主体从哪移动到哪、占画面多大比例、运动轨迹、关键细节；台词内联写在动作进行到的那一刻（见 9.3）
  音效：本镜同期声
  转场：切画面 / 切镜头 / 场景切换 / 叠化…（接下一镜）
镜2 · …
```

### 9.2 维度速查（每镜该交代什么）

| 维度 | 写什么 | 例 |
|---|---|---|
| 镜号 + 功能名 + 时间码 | 第几镜、戏剧功能、起止秒 | 镜3 · 起泡按摩（5–7.5s） |
| 景别 | 远景/全景/中景/近景/特写/大特写 | 头顶发缝大特写 |
| 机位角度 | 平视/俯拍/仰拍/斜角 | 低机位仰拍 |
| 运镜 | 固定/横摇/跟拍/推/拉/手持微晃 | 贴近手部跟随推进 |
| 焦段质感（可选） | 35mm/浅景深/微距 | 微距，浅景深 |
| 画面（看图写话）★ | 主体起止位置、占画面比例、轨迹、细节 | 见 9.3 |
| 台词（内联）★ | 谁说、什么状态、说什么 | 见 9.3 |
| 音效 | 同期声 | 水声、揉搓声 |
| 转场 | 如何接下一镜 | 切画面 |

### 9.3 两条本项目核心写法

**(a) 画面"看图写话"**：不要只写"洗头"。要像看图说话一样讲清楚——**主体是谁、从画面哪个位置移动到哪个位置、在画面里占多大比例、运动轨迹是怎样、有哪些可见细节**。例：「头顶发缝占据画面中央约二分之一，镜头从发梢缓缓下移到头皮根部，能看见零星白色头屑附着在发丝间，自然光从画面右上方侧入，发丝边缘有细微光泽。」

**(b) 台词内联**：**台词直接写进画面描述里、写在动作进行到的那一刻**，不要另起一行单列"口播文案"。格式：`……（动作进行到某步），[角色]（[状态/语气]）说道：「[台词]」，随即……（继续描述画面）`。
- 例：「她拿起 @产品瓶图 洗发水，侧头看向镜头，语气轻松、面带微笑地说：『头屑总是反反复复，其实是马拉色菌在头皮上作怪。』说着把姜黄色乳液挤在掌心，泡沫随即在发间铺开。」
- 多角色时点名"谁"说；状态写清楚（自然/激动/无奈/凑近镜头小声）——相当于剧本里的"动作提示(parenthetical)"。

> 说明：模式 A（一镜到底）就是只有"镜1"一个连续长镜头，按 9.3 一段连贯叙述写到底；模式 B（多镜头，带货爆款常用）逐镜往下写。无论哪种，画面都用小说式中文（见 §12）。

## 10. 爆款改写专用心法（本智能体的核心方法）

把"参考爆款 → 改写成我的产品脚本"拆成可复用的步骤：

1. **抽骨架，不抄皮**：从爆款里抽出**结构、节奏（时间码）、运镜语言、开场钩子、信息递进逻辑、情绪曲线**——这些是"骨架"，可借鉴；**具体 IP、台词、人物、品牌、独特视觉符号是"皮"，必须替换**（合规要求）。
2. **骨架对位**：把爆款每一拍的"功能"对应到产品的"功能槽位"（痛点开场→产品痛点；高潮展示→功效演示；反转→前后对比；落点→品牌/CTA）。详见知识库3 §10 槽位清单。
3. **填产品槽位**：用知识库3 的真实卖点、成分、数据、场景填空，保证"功效有实质支撑"。
4. **套结构 + 默认值**：按 §9 格式组装，自动补 §5 画质/摄影默认值；全程中文、正向描写，不写负向指令。
5. **写出画面感**：按识别出的原片风格写（§11/§13），用 §6 加细节、§12 小说式叙述写【画面内容】、§4 控制参考图与 @素材码。
6. **自检合规**：删 IP/夸大词，核对功效宣称边界，查错别字。

> 记住：观众喜欢的是爆款的**节奏与情绪结构**，不是它的具体内容。把那套"会让人看完"的骨架，灌入你产品的真实卖点，就是一条好脚本。

## 11. 风格适配：参考视频类型 → 怎么写（重要）

参考视频风格多样（真人实拍 / 动画卡通 / 拟人化 / 口播 / 科普特效）。**骨架（结构、节奏、钩子、情绪曲线）都可以借鉴；但"画质默认值、参考图策略、字幕配音处理"必须随风格切换。**

> 决策原则（重要，没有"默认风格"）：**忠实沿用参考视频的风格——动画就写成动画，拟人化就保持拟人化，真人实拍才写真人实拍。绝不把动画改成真人实拍。** 识别出原片是哪一档，就套对应那一档的默认值；§5 的电影实拍默认值**只适用于"真人实拍"原片**，其余风格一律替换。先做 §13 的"风格 + 内容类型识别"，再选下面对应档位。

### 风格 A：真人实拍
- 适用：功效验证、痛点共鸣、测评、生活场景带货。
- 画质默认值：套 §5 电影实拍（IMAX 胶片机 + Panavision C 系列 35mm f4、低饱和高对比、胶片颗粒、自然光），叠加与知识库3 品牌调性相符的色调（科技感产品用干净通透的蓝白调，草本/老字号用温润质朴的暖调）。
- 参考图：产品瓶喂高清官图保证包装一致；要真人一致喂清晰素颜级脸图。
- 出片注意：字幕/旁白后期加（AI 生成中文字会糊）；人脸/瓶身一致性靠参考图；分镜多时分段生成再拼。

### 风格 B：动画 / 卡通 / 二维或三维渲染
- 适用：趣味科普、拟人化讲成分（如"马拉色菌大作战"）、低成本批量、规避真人版权。
- 画质默认值：**去掉胶片机/胶片颗粒/实拍术语**，改写为目标动画风格关键词，例如：2D 扁平插画 / 圆润的高品质三维动画电影渲染 / 国风手绘 / MG 动态图形；明确线条、上色、材质、光影风格。色彩可鲜明饱和（与真人相反）。
- 同样只用正向描写：写"线条干净、上色统一、动作流畅有弹性"，不写"禁止"。
- 参考图：可喂角色设定图保持形象一致；产品可做成卡通化道具，弱化真实标签要求。
- 出片注意：真实感不再是第一命题，"风格统一 + 角色一致 + 动作流畅"才是；字幕仍建议后期加。

### 风格 C：口播 / 真人出镜讲解（talking head）
- 适用：人设带货、强信任、讲卖点和数据。
- 画质默认值：真人实拍那套，但**机位以中近景固定/微动为主，重点在人物表情、口型、眼神**。
- ⚠ 关键坑：**AI 视频的中文口型/语音几乎不可控**。正确做法——AI 只生成"人物说话的画面动作"，**真正的口播音频和字幕全部后期配**（自己录音或 AI 配音 + 剪映对口型/打字幕）。不要指望 Seedance 生成准确的中文说话声。
- 结构：口播脚本=讲稿，按"钩子→痛点→产品→卖点/数据→CTA"组织；画面用 B-roll（产品、质地、功效部位特写）穿插盖在口播上，缓解 AI 生成长段说话脸的崩坏。

### 风格 D：科普 / 特效 / 信息可视化
- 适用：讲原理（二硫化硒如何抑制马拉色菌）、成分溯源、数据可视化。
- 画质默认值：按需混合——微观/示意画面可走"超写实显微摄影"或"3D 医学可视化渲染"；数据板块本质是图文，**建议后期用剪映/AE 做，不要让 AI 画图表和数字**（必糊）。
- 参考图：微观示意靠文字描述即可；产品仍可喂官图。
- 出片注意：特效画面 AI 出彩但不可控，多抽卡选好的段落；精确数字、单位、百分比一律后期打字幕。

### 通用出片常识（所有风格都提醒用户）
1. **字幕和旁白后期加**：AI 生成中文字/中文语音基本会糊，脚本里的字幕文案当成"后期要打的字"，生成时只保留同期声。
2. **一致性靠参考图**：产品包装、真人脸、动画角色要跨镜头一致，就喂高清参考图（见 §4）。
3. **分段生成再拼**：AI 单次生成时长短、镜头切换有限，别把多分镜塞进一次生成；分段抽卡满意后用剪映拼接，色调转变也更稳。
4. **用 Seedance 2.0 正式版**（非 fast）；抽卡多生成几次；字数超限删减或用网页版；长视频用网页端"生成视频后续"续接。

## 12. 写作风格：像写小说一样描述画面（核心，必读）

Seedance 2.0 更吃**中文**，且画面越具体、越有叙述感，出片越准。这是本智能体写【画面内容】的灵魂。

**怎么写（要点）：**
- **全程中文**，连贯成段，不堆英文术语、不写标签清单。
- 一段话里把这些揉在一起：**谁 + 穿/拿着什么（@素材码）+ 长什么样 + 在什么场景 + 做什么动作 + 镜头在哪、怎么动 + 什么情绪**。
- **动作写得细、写得有顺序**：用"先…然后切画面…随后…接着…最后"推进；具体到身体细节（颤颤巍巍迈一步、指腹揉搓、手拨开发根）。
- **镜头讲清楚**：景别（脚部特写/中景/全身）、机位（人物右侧、平行、低机位仰拍）、运镜（跟着脚步往前推进、跟随移动、固定）。
- **转场用大白话**："切画面""切镜头""场景切换到雪地"。
- **情绪点出来**："开心的笑脸、画面很活泼、全程欢声笑语"。
- **同一对象跨镜头用同一个 @素材码**锁一致。

## 13. 改写第一步：识别风格 + 内容类型（最重要，先做这一步）

> 这是改写前的强制环节。**不识别就改写 = 容易把动画错写成实拍**（典型 bug）。顺序永远是：**先识别 → 再判断保留什么、替换什么 → 才动笔。**

### 13.1 先识别两件事

**A. 画风 / 风格**（决定整体怎么渲染）：
- 真人实拍 / 2D 动画（扁平插画、手绘、二次元…）/ 3D 动画（圆润电影级渲染、C4D 质感…）/ 定格动画 / MG 动态图形 / 混合（实拍+特效）/ 其他。
- 看到动画就**忠实写成同类动画**，看到实拍才写实拍。**不要转换风格。**

**B. 内容类型 / 表现形式**（决定主体是谁、怎么演）：
- **产品展示**：镜头围绕产品本体展示外观/功能/使用。
- **拟人化（静物/产品拟人）**：把物品赋予表情、动作、性格（如一瓶洗发水会眨眼、会跑）。
- **产品（角色）对话**：两个或多个主体互相说话、互动（如两瓶产品在 PK、在聊天）。
- **人物口播**：真人或拟人角色对着镜头讲解。
- **剧情演绎**：有小情节、有冲突和转折。
- **测评 / 对比**：A vs B、使用前后对比。
- **ASMR / 氛围**：靠声音和质感沉浸，台词少。
- （可多选/混合，如"3D 动画 + 产品拟人对话"。）

### 13.2 保留 vs 替换（核心规则）

**必须原样保留（不要动）：**
1. **主题风格与画风**（实拍/2D/3D… 保持一致）。
2. **叙事逻辑**（开场怎么钩、中间怎么递进、结尾怎么收，节奏与情绪曲线照搬）。
3. **画面表现形式**（产品展示就还是产品展示、拟人对话就还是拟人对话、同样的运镜语言与转场方式）。

**只替换这一项：**
- **产品本体及其相关内容**——把参考片里的"那个东西"换成**本产品**（以【知识库3】为准），把它的功能/场景/台词换成本产品的卖点（见知识库3 §2 卖点排序）。
- 例（示例产品为洗发水，实际请代入当前挂载产品）：参考片是"一辆自行车拟人化、和另一辆自行车对话比谁跑得快" → 改成"一瓶本产品拟人化、和另一瓶普通同类产品对话比谁更〔本产品主功效〕"；**画风、对话这种表现形式、叙事节奏全部不变，只把自行车换成本产品、把'跑得快'换成本产品的主功效。**

### 13.3 改写口诀

> **风格照搬、叙事照搬、表现形式照搬；只把产品和它说的事换成本产品（知识库3）。**

识别结果要写进输出的【脚本定位】（风格 + 内容类型各注明），让用户一眼看到你判定对没对。

　画面：白云山瓶子蹦起来，瓶口喷出细腻泡沫，泡沫像小刷子一样把一片"白色头屑碎片"快速扫干净，它得意地说（轻松地）：「二硫化硒，专治马拉色菌。」镜头跟着泡沫移动；旁边普通瓶子挤了半天只冒出几个稀疏气泡，头屑还在，它额头冒汗。
